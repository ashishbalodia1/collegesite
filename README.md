# TechMart - Professional E-Commerce Website

A complete, professional e-commerce website built for college students to showcase as their placement projects.

## 🌟 Features

### Pages Included
- **Home** - Hero section, categories, featured products, and features
- **Services** - Comprehensive services offered
- **Registration** - Vendor registration with complete form validation
- **Blogs** - Blog posts with category filtering and newsletter subscription
- **About** - Company information, team, mission & vision, timeline
- **Feedback** - Customer feedback form with star ratings
- **Login/Signup** - Complete authentication system with form validation

### Key Features
- ✅ **Fully Functional Authentication** - Working login/signup with localStorage
- ✅ **Professional Design** - Clean, modern UI inspired by Flipkart/Amazon
- ✅ **Responsive Layout** - Works perfectly on desktop, tablet, and mobile
- ✅ **Form Validations** - Client-side validation for all forms
- ✅ **Interactive Components** - Star ratings, filters, toasts, animations
- ✅ **Shopping Cart** - Add to cart functionality
- ✅ **User Session Management** - Login persistence and logout
- ✅ **Data Persistence** - LocalStorage for user data and cart

## 🎨 Design

- **Color Scheme**: Blue (#2874f0) and Orange (#ff9f00) - Professional e-commerce colors
- **Font**: Segoe UI for clean, modern typography
- **Icons**: Font Awesome 6.4.0
- **Images**: High-quality Unsplash images

## 🚀 Getting Started

### Installation
1. Open `index.html` in your web browser
2. That's it! The website is ready to use

## 💻 Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Grid and Flexbox
- **JavaScript (ES6+)** - Vanilla JS for all functionality
- **LocalStorage API** - Data persistence
- **Font Awesome** - Icon library

## 📱 Responsive Design

Works perfectly on desktop, tablet, and mobile devices.
