# TechMart - Student E-Commerce Platform 🎓

A professional, feature-rich e-commerce website designed specifically for college students. Perfect for placement projects and demonstrations with 10+ advanced features!

## 🌟 Key Highlights

- **Student-Focused** - Special discounts, EMI options, college partnerships
- **Advanced Features** - Wishlist, Quick View, Flash Deals, Product Comparison
- **Fully Functional** - Working authentication, cart, and form validations
- **Professional Design** - Flipkart/Amazon style with modern UI/UX
- **Pure Vanilla JS** - No frameworks, 4,700+ lines of clean code

## ✨ Student-Centric Features

### 🎯 For Students
- **Exclusive Student Discounts** - 20% off with code STUDENT20
- **Flash Deals** - Limited-time offers with live countdown timer
- **EMI Options** - Easy payment plans for expensive items
- **Free Shipping** - On orders above ₹500
- **College Partnerships** - Verified by IIT, NIT, and top institutions
- **Student Testimonials** - Real reviews from college students

### 🛍️ Shopping Features
- **Wishlist System** - Save products, persistent storage, quick access
- **Quick View Modal** - Preview products without page reload
- **Smart Shopping Cart** - Add/remove items with real-time updates
- **Product Comparison** - Compare specs and prices side-by-side
- **Recently Viewed** - Track browsing history automatically
- **Category Filtering** - Browse by Electronics, Fashion, Books, etc.

### 🔐 Authentication
- **Complete Login/Signup** - User registration and authentication
- **Session Management** - Persistent login with localStorage
- **Form Validation** - Email, phone, password strength checking
- **User Profile** - Display logged-in user information

## 📄 Complete Page List

1. **Home** (`index.html`) - Hero section, flash deals, products, testimonials, partnerships
2. **Services** (`services.html`) - 9 comprehensive services with icons
3. **Registration** (`registration.html`) - Vendor registration with PAN/GST validation
4. **Blogs** (`blogs.html`) - Tech articles with category filtering
5. **About** (`about.html`) - Company info, team, mission, timeline, statistics
6. **Feedback** (`feedback.html`) - Star rating system and feedback form
7. **Login/Signup** (`login.html`) - Complete authentication system
8. **Wishlist** (`wishlist.html`) - Manage saved products with add to cart
9. **Compare** (`compare.html`) - Product comparison table (Coming soon)
